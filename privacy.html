Privacy

Last updated: 25 November 2026

BloxWisp is a list of Roblox games. This page says exactly what the site does with data, in plain words.

What the site does not do

  • No accounts, no sign-up, no email list.
  • No ads, no analytics, no tracking pixels (no Google Analytics, no Facebook pixel, nothing similar).
  • No cookies.
  • The fonts, scripts and game icons are served from this site itself, not from outside services.

What is stored in your own browser

The site uses your browser's local storage (it never leaves your device) for:

  • your language choice;
  • your accessibility settings, if you change them;
  • a cache of game descriptions translated into your language, and of game images and IDs looked up from Roblox, so they do not have to be fetched again.

You can clear all of it by deleting this site's data in your browser settings.

When the site talks to other services

  • Translation. In English nothing is sent. If you pick another language, the English game descriptions (only the description text, nothing about you) are sent to a translation service (Google Translate, with MyMemory as a backup) so they can be shown in your language. Like any web request, this reveals your IP address to that service.
  • Roblox images. If a game's icon is not stored on this site, the page asks Roblox for it through the public proxy allorigins.win. Again only the game's name or ID is sent.
  • Hosting. The site is hosted on GitHub Pages. GitHub may keep standard server logs (such as IP addresses) as described in GitHub's privacy statement.
  • Links out. Play buttons open the game's page on roblox.com. From there, Roblox's own privacy policy applies.

Children

The site does not ask anyone for personal information, so it collects none from children either.

Changes

If the site starts doing something new with data, this page will be updated first, with a new date at the top.
